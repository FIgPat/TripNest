# TripNest

เพิ่มข้อมูลที่พักจากไฟล์ Excel จำนวน 30 รายการแล้ว โดยยังใช้ระบบรูปภาพภายในเครื่องแบบเดิมบ

## รูปภาพ
แต่ละที่พักใช้ path `/images/hotel<ID>.webp` และ `/images/hotel<ID>-2.webp` จำนวน 2 รูป
สำหรับ ID 1-30 ในแพ็กเกจนี้ใช้รูปตัวอย่างจากชุดเดิมเพื่อไม่ให้รูปแตก/หาย และสามารถนำรูป WebP จริงมาแทนที่ไฟล์ชื่อเดียวกันได้ทันที

## รัน
`npm install` แล้ว `npm start` จากนั้นเปิด http://localhost:3000
